## MLP dataset note

The question folder contains the shared master dataset with 1,000 observations. The student notebook uses the student ID (or the sorted suffixes for a pair) to create a reproducible seed and select a group-specific subset of 100 rows. Keep the question notebook and master CSV together when running locally or in Colab.

The answer folder contains the completed reference notebook and its generated 100-row dataset for seed 12345678.

The private working repository contains instructor/reference material and drafts; this public repository is intended for student-facing releases.
